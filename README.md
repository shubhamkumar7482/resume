## 📄 About the Project

This is my personal **developer portfolio website**, built to showcase my **skills, projects, and experience** as a **PHP & Laravel Developer**.  
It highlights my journey in web development, including hands-on experience with **E-commerce platforms, API integrations, and dynamic web applications**.

The website is fully **responsive**, visually clean, and optimized for both desktop and mobile devices.

---

## 🧩 Features

- 🏠 **Home Section** – Brief introduction with professional summary and download resume option.  
- 🙋‍♂️ **About Section** – Displays personal info, education, and professional experience in timeline format.  
- 💻 **Skills Section** – Showcases key technical skills using modern glass-effect cards.  
- 🧠 **Experience Section** – Timeline of previous roles, technologies used, and key responsibilities.  
- 📞 **Contact Section** – Contact form with social links (LinkedIn, GitHub, Portfolio).  
- 🔢 **Animated Counters** – Display metrics like total experience, projects completed, and API integrations.  
- 📱 **Responsive Design** – Works seamlessly across all screen sizes (Bootstrap-based grid system).
